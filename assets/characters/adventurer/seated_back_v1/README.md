Generated with the built-in image tool from the existing adventurer rear-standing image and side deck-chair sheet. No existing animation was replaced. The upright first draft is retained as `seated_back_sheet.png`; the selected revision is `seated_back_recline_sheet.png`.

The four numbered PNGs are exact copies of the selected sheet. Pi animation frames use per-frame crops, fixed standing reference height, foot anchors and manually traced skeletons in full-image normalized coordinates. Hidden far limbs are marked inferred. Furniture remains part of the scene and masks the sprite separately.

Animation Grid roles: `seated_back` (breathing loop), `seated_back_sit_down` and `seated_back_get_up` (one-shot transitions). Eligible scenes: beach and apartment. Pose placements are left for the user to arrange; transitions do not appear as ordinary stageable gestures.

Prompt: six isolated equal-cell sprites of the same blond ponytailed adventurer, teal long coat, dark trousers and brown boots; rear three-quarter view, standing, lowering, sitting, then three breathing frames reclined backward approximately 45 degrees. Fixed feet, head size and palette; transparent background, no chair, scene, shadows, labels or borders. Reference images: `../poses/v1_stand_up_0.png` and `../deck_chair_v1/deck_chair_sheet.png`.
