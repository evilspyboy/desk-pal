# Rest transitions

> Artwork/provenance record. Runtime selection, crops, anchors and placements come from saved configuration; this record is not the current deployment or task list. See the [documentation index](../../../../docs/index.md).


Generated with the built-in image generation tool. Original generated RGBA pixels are preserved in `raw/`. Three intermediate frames connect the existing seated, lying and standing sprites. The manifest defines four play-once sequences: sit_down, stand_from_sit, lie_down and stand_from_sleep. Entry sequences reverse the corresponding getting-up frames. Runtime alignment uses crop, reference_height and anchor_x metadata; the original idle animation sprites were not replaced.
