# Screen-prop artwork

> Artwork/provenance record. Runtime selection, crops, anchors and placements come from saved configuration; this record is not the current deployment or task list. See the [documentation index](../../../docs/index.md).


Four-frame, 2 FPS pixel-art loops created with the built-in imagegen tool. The original generated sheet is `source_sheet.png`; numbered PNGs are extracted cells. Hash-named copies in the parent props directory are the runtime assets.

Pose-linked placement chooses a random selected library animation on activation and holds it for that visit, hiding when inactive or asleep. Frames and playback choices can be changed through the prop editor without changing placement geometry. See [custom interactive props](../../../docs/interactive-tv.md).
