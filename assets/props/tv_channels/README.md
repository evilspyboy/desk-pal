# Screen-prop animation assets

> Artwork/provenance record. Runtime selection, crops, anchors and placements come from saved configuration; this record is not the current deployment or task list. See the [documentation index](../../../docs/index.md).


Four-frame, 2 FPS pixel-art loops created with the built-in imagegen tool. Each source sheet contains a 2-by-2 grid, extracted in row-major order into numbered PNG frames and scaled to 512-by-384 with nearest-neighbour sampling. Hash-named copies in the parent props directory are the runtime assets.

`channels.json` records reusable sequence definitions and generation prompts without personal settings. The scene prop and interactive overlay share the selected library choices. Users can upload replacement sequences and choose them through the prop editor; see [custom interactive props](../../../docs/interactive-tv.md).
