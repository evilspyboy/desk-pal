Agent activity hooks

Existing optional MCP bridge

The separate Desk-Pal MCP bridge runs on your agent’s computer. An agent explicitly reports started, researching, coding, completed or needs-attention events; Desk-Pal plays the mapped reactions.

It works with an MCP-capable host using OpenAI, Gemini, Claude or a local model. This does not automatically observe agents or connect a model to Desk-Pal. Automatic lifecycle hooks and conversational agent mode are planned.

Import integrations/agent-mcp/integration.json through App & Action Studio, then map its events. Follow integrations/agent-mcp/README.md to launch the bridge on the agent host.

Speech output and input

Piper output · STT not implemented

Enter an official Piper voice ID. Browse voices and listen to samples. Downloads go to this device; the display keeps running.

Give it a unique name. The pair is checked before it appears in the voice list. Maximum model size: 256 MB. Multi-speaker models use their default speaker.

When enabled, the voice stays in memory after its first use for faster responses. When disabled, it unloads after each request. Disabling speech or pressing Stop also releases it. Volume/output come from Hardware.

Save settings before testing a changed voice or model.

Local TTS can speak test text through the selected hardware speaker. Automatically reading briefings and attention messages is a separate future option. Speech to text (STT) would capture deliberate push-to-talk input through the microphone.

These are separate preferences, not a claim that every provider supports both capabilities. Local speech services can run on another computer. Piper supplies local speech; transcription backends remain under evaluation. Automatic listening is disabled.

Interactive Voice Attention

Desk-Pal can escalate its voice alert when important events (orders, fuel drops, anomalies) need attention. It waits for radar presence before speaking, and gives up cleanly if ignored.

Voice Recognition & Sentry (STT)

faster-whisper · local edge speech recognition

Recognize voice input directly on device using lightweight faster-whisper. Tap the character sprite (push to talk) or trigger with a wake word.

When checked, the Whisper model stays loaded in RAM (~120 MB), allowing instant transcription when you poke the sprite. Unchecked, it releases memory after each phrase.

Stops listening after 2.0 seconds of silence so natural pauses between sentences are preserved.
