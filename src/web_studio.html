Foreground objects

Click an object on the scene to select it. Orange marks its visible outline; the red footprint controls where walking is blocked.

The ground footprint blocks walking. Trace the visible outline to hide the character when it walks behind the object. The existing background artwork is used.

For objects you can walk around, fit the linked ground block to the base and leave depth blank. Its sloping front edge controls which parts cover the character. Use Always in front for beach-edge plants and rocks. Turning hiding off keeps the ground blocked.

Day / night location

Use a timezone name such as Australia/Sydney, Europe/London or America/New_York. Leave blank to use the Pi’s timezone. Named zones follow daylight saving automatically.
