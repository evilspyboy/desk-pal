Physical buttons · GPIO

Use BCM GPIO numbers, not physical pin numbers. Button ID 1 is sleep/wake; ID 6 is shutdown. Other IDs can be assigned in App & Action Studio. Buttons connect GPIO to ground using pull-ups. I²C/UART GPIOs are reserved while those readers are enabled.

Movement instructions

Raw motion readings

The box uses calibrated axes for tilt and bias-corrected gyro for relative turns. Heading is relative to this preview session and can drift; there is no compass. Movement can temporarily distort tilt. A loose sensor does not show case orientation. Map optional character reactions in App & Action Studio → Sensors. Return detection checks tilt and stillness; this sensor cannot verify the original table location or compass direction.

Light · BH1750

Shared with radar. Uses the scene day/night location and timezone. Manual sleep still works. Outside this window the normal lux policy applies.

Sustained darkness uses the usual sleep animation and screen-off flow. Wake occurs above the threshold plus margin. Manual sleep stays asleep. A manual wake gets the time above before dark sleep can resume; an open information popup also keeps it awake. A shaded sensor may read zero—measure daytime and lights-off levels before enabling.
